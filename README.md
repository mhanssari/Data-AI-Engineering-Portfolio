# Mohammad Hassan Anssari data engineering portfolio

Lead Data Engineer | Data Platform & Analytics Lead

Independent case studies in data engineering, analytics engineering and BI, each built around a business decision. All data is synthetic, generated by seeded scripts in the repository.

**Start with [case 06](cases/06-p2p-agentic-reconciliation/README.md)**, which is the one with working code: an ontology-mapped model, incremental ingestion, supplier entity resolution, SQL matching and controls, and a Neo4j projection, with tests and recorded evidence. The other cases are plans.

## Conventions

- One repository, self-contained cases. Dependencies and settings belong to the case that uses them.
- Every case separates measured results from proposed production designs, and declares grain and keys for its tables. "Planned" means designed, not built.
- Nothing is deployed unless a case says so. Local prototypes are labelled as such.
- No licence has been selected yet.
