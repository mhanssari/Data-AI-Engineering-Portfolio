# Mohammad Hassan Anssari data engineering portfolio

Lead Data Engineer | Data Platform & Analytics Lead

Independent case studies in data engineering, analytics engineering and BI, each built around a business decision. All data is synthetic, generated by seeded scripts in the repository.

Implemented cases have working code, tests and recorded evidence:

- **[Case 02, retail loyalty analytics](cases/02-retail-loyalty-analytics/README.md)**, for analytics engineering and BI. It includes:
  - dbt models with an incremental fact proven equal to a full refresh, type 2 history and a snapshot;
  - enforced contracts, invariant tests and source freshness;
  - cohort and retention metrics with explicit maturity rules;
  - a Power BI model and report kept as text, reconciled to SQL;
  - an opt-in Airflow backfill.
- **[Case 06, agentic procure-to-pay reconciliation](cases/06-p2p-agentic-reconciliation/README.md)**, for finance data and AI. It includes:
  - an ontology-mapped model, supplier entity resolution, and SQL matching and controls;
  - a Neo4j projection and permission-aware retrieval;
  - guarded agents, row-level security and data contracts.

- **[Case 03, payment reconciliation](cases/03-payment-reconciliation/README.md)** has a validated batch implementation with seeded defects, per-currency SQL controls, late-file recovery and rerun evidence through the shared Airflow. Batch, shared Kafka and Spark intake have passing CI. The watermarked live query and SQL operational views are validated locally, including duplicates, reference refresh and checkpoint restart; forced crash recovery and late backfill remain planned.

Cases 01, 04 and 05 are plans.

## Conventions

- One repository, self-contained cases. Dependencies and settings belong to the case that uses them; shared services live under [platform](platform/README.md).
- Every case separates measured results from proposed production designs, and declares grain and keys for its tables. "Planned" means designed, not built.
- Nothing is deployed unless a case says so. Local prototypes are labelled as such.
- No licence has been selected yet.
