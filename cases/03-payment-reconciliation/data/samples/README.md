# Data Samples

Static sample files are not required. The seeded [batch generator](../../src/payrecon/generator.py) reproduces source files; [batch scenarios](../../src/payrecon/scenarios.py) declare expected planted outcomes. Streaming fixtures are generated by the [intake producer](../../src/payrecon/streaming/producer.py), [phased live fixture](../../src/payrecon/streaming/live_fixture.py) and [state profile](../../src/payrecon/streaming/state_profile.py).

Generated files and diagnostic output are ignored by Git. See [data provenance](../README.md) and the [case evidence](../../evidence/README.md) for actual validation; no external or employer data is used.
