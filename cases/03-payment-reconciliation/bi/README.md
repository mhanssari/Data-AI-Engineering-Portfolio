# Consumption

The MVP exposes PostgreSQL reconciliation tables and `stream.operation_minute`, with separate `stream-status` readiness diagnostics. Their [metric definitions](../docs/metrics.md), [grains](../docs/data-model.md) and [inspection guide](../streaming/README.md) are documented.

There is no BI report or separate semantic model. A dashboard is an optional presentation extension, not an unfinished pipeline requirement.
